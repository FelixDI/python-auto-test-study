# git
```
clone	把远程仓库下载到本地
status	查看当前文件状态（改了哪些、新增了哪些）
add	把文件加入暂存区，准备提交
commit	把暂存区的文件正式提交到本地仓库
push	把本地提交推送到 GitHub
pull	拉取远程仓库的最新代码
branch	创建分支、切换分支
.gitignore	忽略不需要版本控制的文件/目录
```

# coze
```
搭建测试用例生成工作流：
开始（上传项目文档（PRD、需求规范、测试用例模板等）
插件（“链接读取”获取网页、pdf、doc、docx、xlsx、csv、text 内容）
大模型（系统提示词：设定人设    用户提示词：双花括号添加变量）
结束

插件 = 工作流的“手”，能自动解析文件、提取文字
完整链路：上传文件 → 插件提取文字 → LLM 生成用例 → 输出 Markdown


资源库--->"+资源"--->工作流/知识库
知识库 = 工作流的“记忆”，让 AI 学习企业项目文档后生成更精准的用例
```
