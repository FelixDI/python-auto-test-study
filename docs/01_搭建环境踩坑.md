# 按正常流程add commit首次提交、
# GitHub 上新建一个完全空白的仓库（不勾选 README、不勾选.gitignore、不勾选 License）
# 关联远程仓库 SSH 地址,push推送
# 这样既避免了不必要的 Git 初始化，又不会因为忘记 .gitignore 而踩坑。
