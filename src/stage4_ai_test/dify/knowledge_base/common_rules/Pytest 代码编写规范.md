# Pytest 代码编写规范
## 一、命名规则
1. 测试文件：以 `test_` 开头，下划线命名（例：test_products.py）
2. 测试类：以 `Test` 开头，大驼峰命名（例：TestProducts）
3. 测试函数/方法：以 `test_` 开头，下划线命名（例：test_get_all_products）
## 二、断言规范
1. 使用 pytest 原生 assert 断言
2. 优先断言响应状态码，再断言响应体核心字段
3. 断言信息明确，失败时可快速定位问题
## 三、代码结构
1. 单接口测试：导入依赖 → 发送请求 → 断言结果
2. 业务流测试：按步骤调用接口，传递依赖参数
## 四、通用约定
1. 接口根地址统一管理，不硬编码在每个用例中
2. 测试数据与测试逻辑分离
3. 统一用日志输出执行信息，不使用裸 print
